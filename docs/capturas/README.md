# Capturas de pantalla

Estas imágenes se usan como vista previa en el README principal del proyecto.

Para actualizarlas, reemplaza los archivos manteniendo los mismos nombres y una proporción de 1600 × 1000 px:

| Archivo | Módulo |
| --- | --- |
| `ventas.png` | Punto de venta |
| `inventario.png` | Control de inventario |
| `etiquetas.png` | Impresión de etiquetas |
| `reportes.png` | Panel de reportes |

Las capturas actuales son ilustrativas y reproducen la interfaz de la aplicación. Se recomienda reemplazarlas por capturas reales de la versión publicada antes de distribuir el repositorio.
